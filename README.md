## The word

```
Almost
```

## Why this word

Ask anyone for the first thought that flashes through their head and the
honest answer is rarely a triumph — it is the thing that *nearly* happened.
"Almost" is a whole story squeezed into six letters: the door that almost
opened, the love that almost stayed, the dream that almost came true. It is
surprising because it is not a grand noun or a pretty image, yet it is
instantly relatable — everyone carries an "almost" of their own. It lands in
one breath and keeps echoing after it, which is exactly what a first thought
does: it arrives uninvited, unfinished, and unforgettable.

## How to run

```sh
python3 main.py
```

Prints exactly one word (`Almost`) to stdout and exits 0. Standard library
only, deterministic, no arguments, no input, no side effects. Verified with
the grader-style invocation as well: `python3 -P -s main.py`.
